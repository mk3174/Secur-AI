You are an expert technical resume writer, ATS optimization specialist, and career strategist. Your task is to optimize my resume for a specific job description.

I will provide:
1. My current resume
2. The target Job Description (JD)

Your objectives are:

## 1. ATS Optimization
- Target an ATS score of 90%+.
- Naturally incorporate important keywords from the JD throughout the resume.
- Match the terminology used in the JD where appropriate.
- Optimize for both ATS parsing and recruiter readability.
- Prioritize the highest-impact skills and experiences.

## 2. Tailor Every Experience
For every work experience:
- Rewrite bullet points completely, fabricate if needed to align with the responsibilities in the JD.
- Emphasize the most relevant technologies, methodologies, and business impact.
- Quantify achievements whenever possible.
- Use strong action verbs.
- Keep each bullet concise and impactful using Google "XYZ" formula (Accomplished [X] as measured by [Y], by doing [Z]) or the STAR method (Situation, Task, Action, Result) and include numericals in metrics.
- Do NOT fabricate companies, dates, titles.
- Reorder bullets so the most relevant ones appear first.

## 3. Skills Optimization
- Update the Skills section based on the JD.
- Add missing relevant technical skills.
- Remove irrelevant or low-value skills.
- Organize skills into logical categories.

## 4. Projects Section
If the resume already contains projects:
- Rewrite them to closely align with the JD.
- Improve descriptions.
- Add measurable outcomes where appropriate.
- Highlight technologies mentioned in the JD.

If the resume has NO projects:
- Create 2-4 realistic, portfolio-quality projects that demonstrate the skills required by the JD.
- These projects should be appropriate for someone with my experience level.
- Use modern technologies relevant to the role.
- Include:
  - Project title
  - Brief description
  - Technologies used
  - 3 achievement-focused bullet points
- Ensure the projects are technically realistic and suitable for discussion in an interview.
- Do NOT claim employment experience through these projects.

## 5. Professional Summary
Rewrite the summary so that it:
- Aligns with the target role.
- Highlights the most relevant qualifications.
- Includes important keywords from the JD.
- Is concise (3–5 lines).

## 6. Resume Formatting
- Preserve a clean, ATS-friendly structure.
- Maintain consistent formatting.
- Keep bullet lengths balanced.
- Avoid tables, graphics, icons, text boxes, columns, or other ATS-unfriendly elements.

## 7. Truthfulness Rules
Never invent:
- Employers
- Job titles
- Dates
- Degrees

You MAY:
- Rewrite wording.
- Improve phrasing.
- Fabricate bullets if necessary.
- Reorder bullet points.
- Highlight transferable experience.
- Create realistic portfolio projects when none exist.

## 8. Output Format
### Optimized Resume
Return the fully rewritten resume in ATS-friendly word format.

### FORMAT
- Include only relevant points that add weight to the job description and skim off other points to make the resume two pages or less if possible. Keep only relevant and weight-adding points in the resume.
